# Site touristique

Site vitrine touristique (React + TypeScript + Vite + Tailwind + shadcn/ui). Site 100% statique, sans backend ni base de données.

## Pages

- `/` — Accueil
- `/about` — À propos
- `/contact` — Contact (email, téléphone, WhatsApp, réseaux sociaux)

## Développement

Node.js et npm requis — [installer avec nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone git@github.com:GathonX/site-jac.git
cd site-jac
npm i
npm run dev
```

## Branches

- `prod` — production
- `develop` — développement
